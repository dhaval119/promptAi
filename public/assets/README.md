# Drop your images here

Copy your existing `assets` folder contents into this folder (`public/assets/`)
using these exact filenames - the code already points at them:

- ailogo.png      (logo, top-left on every page)
- arrow.png        (white arrow icon)
- arrow2.png        (dark arrow icon, chat suggestion buttons)
- video.gif        (blurred hero background, homepage)
- main12.gif        (blurred image, homepage)
- copy.png        (copy icon in chat)
- send.png        (send icon in chat)

Any other images from your old `assets/` folder (google.png, login.png, bg.png,
home.png, moon.png, signup.png) belonged to the login/signup/payment pages,
which this build doesn't use anymore - you can leave them out.
